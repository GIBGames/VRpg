# VRPG2 Roleplaying Game System
A system for creating RPG systems in VRChat.

**See an example of this prefab: [SCP RP: Site-97](https://vrchat.com/home/world/wrld_6f23cdc6-be51-49e6-bdf8-b71de828d413) on VRChat!**

Contribute to this project on [our discord.](https://discord.gg/jvZkahu)

## MAJOR UPDATE 9/29/2026
The new update, VRPG2, is **NOT** compatible with previous releases of VRPG. You will need to completely remove VRPG and reinstall.

## Features
* Player Menu - Open with Q on keyboard or clicking your head in VR!
* Dice Rolling
* GM Tools including communication and teleport
* In-character and out-of-character logging and chat
* Character labels and tags
* Map system

## Requirements and Installation

This system requires:
* [VRChat SDK](https://docs.vrchat.com/docs/choosing-your-sdk)

Import the above required packages. Then, import this package. 
This package includes an example scene. Copy the contents of that scene into your scene if desired.
